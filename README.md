# 🌿 Pureza Interior – Landing Page

Este proyecto fue creado para mi amigo Marco como una página web sencilla para promocionar sus productos de **Pureza Interior** (marca de bienestar de FuXion) en varios países.

---

## ¿Qué es esto?

Es una **landing page** (página de aterrizaje) donde los clientes pueden:

- 🎬 Ver un **video tutorial** de cómo comprar con su promoción
- 🛒 Ir directo a la **tienda** para ver precios y comprar
- 💬 Escribir por **WhatsApp** para recibir ayuda
- 📱 Visitar las **redes sociales** (Facebook, TikTok, Instagram)
- 🎁 Conocer los **beneficios exclusivos** (4x1, envío gratis en USA, etc.)

---

## 🌐 Idiomas

La página detecta automáticamente el idioma del navegador del visitante y se ajusta a uno de estos 4 idiomas:

- 🇪🇸 Español
- 🇺🇸 Inglés
- 🇧🇷 Portugués
- 🇫🇷 Francés

También hay un **selector de idiomas** en la parte superior para cambiarlo manualmente.

---

## 📊 Estadísticas

Se integró **Google Tag Manager** para poder ver el tráfico de la página desde Google Analytics: cuántas personas entran, de dónde vienen, qué botones tocan, etc.

---

## 🛠️ ¿Con qué se hizo?

| Herramienta | Para qué se usó |
|---|---|
| HTML | La estructura de la página |
| CSS | Los colores, diseño y animaciones |
| JavaScript | Cambio de idiomas y efectos |
| Google Fonts | Las letras bonitas (Playfair Display, Inter) |
| Vimeo | El video tutorial embebido |

| GitHub Pages | Para que la página esté en internet gratis |
